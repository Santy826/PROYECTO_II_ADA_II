# Carpeta del informe IEEE

Esta carpeta organiza el contenido previo a la redacción final del PDF.

## Flujo recomendado

1. Completar los borradores en `secciones/`.
2. Consolidar en un único documento IEEE.
3. Exportar a PDF para entrega.

## Nota

El informe final debe explicar claramente el modelo y la implementación, pero sin pegar código fuente completo.

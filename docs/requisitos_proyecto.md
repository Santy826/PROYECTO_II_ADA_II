# Requisitos del proyecto (interpretación operativa)

## Entrega

- Informe en PDF vía campus virtual.
- Sustentación individual.
- Grupos de máximo 3 personas.

## Problema

- Valle representado por cuadrado de tamaño `N x N`.
- Ciudades en posiciones enteras `(x, y)`.
- Distancia entre ciudades: Manhattan.
- El concierto no puede ubicarse exactamente en una ciudad.
- Se busca una ubicación relativamente equitativa.

## Implementación solicitada

- Entrada desde un TextArea con formato:
  - Línea 1: `N`
  - Línea 2: `M`
  - Siguientes `M` líneas: `nombre_ciudad x y`
- Botón para generar código reutilizable en MiniZinc.
- Campo de texto para copiar/pegar salida.
- No se acepta devolver solo resultado dentro de la app.

## Contenido mínimo del informe IEEE

1. Modelo del problema.
2. Explicación de implementación (sin incluir código).
3. Pruebas con datos específicos.
4. Análisis de pruebas según tamaño y naturaleza de entrada.
5. Conclusiones.
